# study/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

本目录特有约束：

- **改这里就是改实验**。任何改动先确认它会不会让既有 run 与新 run 不可比；会，就必须换 id（`criteria_id`、`task` 文件名），不原地改。
- 不写代码。这里是数据与声明；逻辑在 `tools/` 与 `analysis/`。
- 数值必须带来源：真值写算法出处，容差写推导出处，token 写切分器与版本。
- 已知的漏洞写进 `known_limits`，不要为了好看而省略——判定层的可信度来自它承认自己管不住什么。
- **选题不许看结局**。基线率是报告对象，不是选择对象；探针只定 k，且预声明不进分析。依据与三条禁忌见 [DESIGN.md](DESIGN.md)。

各文件是谁的输入、改后波及什么，见 [README.md](README.md)。
