# .agents/notes/ — 决策与依据记录

装两类记录，都是「为什么这么定」：

| 类型 | 触发源 | 结构 |
|---|---|---|
| 决策 | 在几个方案里挑了一个 | 问题 / 决策 / 替代方案（强制）/ 影响 |
| 依据 | 做了一次调查或对照 | 背景 / 结论 / 支撑的决策（可选）/ 影响 |

分界只有一条：**做选择**还是**做调查**。事故触发的不在这里，去 `docs/postmortem/`（按需才建）。

**这里只装仪器层（`tools/`、`analysis/`）的决定。** 某一项研究自己的结论与依据，住在该研究的 `notes/` 下——见 [研究组织规则](../../studies/README.md)。

## 规则

- 第 3 行必须是状态行，四值之一：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`。
- `被取代` 必须跟指针行；`已否决` / `已归档` 必须跟一句话理由。
- 归档就地标记，不建 `archived/` 子目录。
- 不建索引文件，不逐篇列清单；找记录靠文件名 `YYYY-MM-DD-<主题>`。
- 写入规则本身见 [AGENTS.md](AGENTS.md)。
