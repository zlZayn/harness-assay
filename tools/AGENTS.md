# tools/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

本目录特有约束：

- **不写研究知识**：任何脚本里出现 arm 名、cue 词、通过标准、具体 run id，就放错了地方。
- 只用标准库。要引第三方依赖先问维护者——记录层零依赖是它可以被无条件信任的原因之一。
- 写状态用**字节**，不用文本模式；写不存在的文件用独占创建（`open(..., "x")`），不覆盖。
- 判定函数必须是纯的：同输入同输出，不读时间、不读随机、不读环境。
- 任何「不许发生」的事都做成退出码，不只打印一句提示。

文件职责与改后必验见 [README.md](README.md)。
